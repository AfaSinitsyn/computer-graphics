# Компьютерная графика — лабораторная работа № 2

Вариант 3: параллелепипед. Номер в списке: 15.

Лабораторная № 2 выполнена на базе первой, на оценку 4: базовое задание
и дополнительные задания 1–3. Код первой лабораторной остаётся в ветке `main`.

Основа: [стартовый проект преподавателя](https://github.com/vladeemerr/vulkan-starter-app).
Используются C++20, Vulkan, GLFW и Dear ImGui.

## Реализовано

- Камера: позиция, поворот по трём осям, угол обзора; матрица вида — обратная матрица камеры.
- Перспективная и ортографическая проекции, преобразования и анимация объекта из первой лабы.
- Процедурные нормали граней параллелепипеда. 24 записи вершин, 12 треугольников.
- Модель Блинн—Фонга во фрагментном шейдере для направленного, точечных и прожекторных источников.
- Изменяемый ambient, альбедо, цвет блика и показатель блеска материала.
- Два набора дескрипторов: сцена (`set=0`) и модель (`set=1`).
- Массивы точечных источников и прожекторов в storage buffers (`std430`, массивы без фиксированного размера).
- Добавление, удаление и настройка источников через ImGui.
- Затухание `1 / distance²`, мягкие края прожектора между внутренним и внешним углами.

## Сборка под Windows / Visual Studio 2022

Нужны компоненты разработки на C++ в Visual Studio 2022, CMake, Git и Vulkan SDK.
Проверить SDK в новом PowerShell:

```powershell
glslc --version
```

Из корня проекта:

```powershell
cmake --preset msvc-debug -A x64
cmake --build build-debug --config Debug --parallel
.\build-debug\Debug\vulkan-starter-app.exe
```

Если ImGui ранее скачан отдельно, а CMake снова не может его скачать:

```powershell
cmake --preset msvc-debug -A x64 "-DFETCHCONTENT_SOURCE_DIR_IMGUI=C:/CG/dependencies/imgui-1.92.9"
```

Последняя команда применима, только если эта папка существует.
Шейдеры компилируются CMake автоматически. Запускать приложение из корня проекта,
где находится папка `shaders`, чтобы оно нашло файлы `.spv`.

## Управление

Панель слева прокручивается колёсиком. Разделы можно сворачивать.

- **Camera**: Position, Rotation, FOV; Reset camera возвращает начальный вид.
- **Object**: положение, поворот, масштаб и анимация из первой лабы.
- **Material**: Albedo, Specular color, Shininess; Use vertex colors включает процедурные цвета первой лабы.
- **Ambient**: цвет и интенсивность окружающего света.
- **Directional light**: направление лучей, цвет и интенсивность.
- **Point lights**: Add point light; у каждого источника есть Position, Color, Intensity и Remove point.
- **Spot lights**: Add spot light; дополнительно Direction, Inner angle, Outer angle и Remove spot.

Начальная сцена содержит один направленный источник. Точечные и прожекторные добавляются кнопками.
Чтобы увидеть их отдельно, установите интенсивность направленного источника в 0.
Направление света задаётся от источника вдоль лучей, нормализуется перед передачей на GPU.
Углы прожектора — половины углов конуса в градусах. Внешний угол не меньше внутреннего;
при равных углах граница жёсткая. FOV влияет на перспективную проекцию;
в ортографической размер видимой области меняется через View height.
