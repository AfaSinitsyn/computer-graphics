# Компьютерная графика — лабораторная работа № 1

Вариант 3: параллелепипед.
Номер в списке: 15.

Основа проекта:
https://github.com/vladeemerr/vulkan-starter-app

Используются C++, Vulkan, GLFW и Dear ImGui.

## Реализовано

- Отрисовка параллелепипеда: 8 вершин, 12 треугольников.
- Переключение перспективной и ортографической проекций.
- Изменение положения, поворота и масштаба.
- Движение и вращение по пространственной траектории.
- Воспроизведение и пауза, настройка скорости, радиуса и высоты траектории.
- Изменение цвета через интерфейс.
- Процедурные цвета вершин, умножаемые на выбранный цвет.

## Сборка под Windows

Нужны Visual Studio 2022 с компонентами разработки на C++,
CMake, Git и Vulkan SDK. Команда glslc должна быть доступна в PATH.

Выполнить из корня проекта:

    cmake --preset msvc-debug -A x64
    cmake --build build-debug --config Debug --parallel

## Запуск

Из корня проекта:

    .\build-debug\Debug\vulkan-starter-app.exe

## Основные файлы

- source/application.cpp — ресурсы Vulkan, интерфейс и отрисовка.
- source/lab_scene.hpp — геометрия, цвета вершин и траектория.
- source/lab_math.hpp — матрицы преобразований и проекций.
- shaders/parallelepiped.vert — вершинный шейдер.
- shaders/parallelepiped.frag — фрагментный шейдер.

Стартовый код окна и инициализации Vulkan взят из проекта преподавателя.
